# Dərsly v2 – IT Business Analysis Layihəsi

## Layihə haqqında

Dərsly v2 onlayn təhsil platformasının biznes və sistem tələblərinin
təhlili və sənədləşdirilməsi məqsədilə hazırlanmış Business Analysis
layihəsidir.

Layihə IT Business Analysis təlimi çərçivəsində hazırlanmışdır.

## Mənim rolum

Business Analyst

## Layihənin məqsədi

Layihənin əsas məqsədi tələbələrin kurslara qeydiyyatı, ödəniş,
dərslərə giriş, tapşırıqların təqdim edilməsi və qiymətləndirilməsi
proseslərinin təhlil edilməsi və sistem tələblərinin sənədləşdirilməsidir.

## Hazırlanmış sənədlər və modellər

- Business Requirements Document (BRD)
- Business Requirements
- User Requirements
- Functional Requirements
- Non-Functional Requirements
- User Stories
- Acceptance Criteria
- BPMN 2.0
- Use Case Diagram
- Entity Relationship Diagram (ERD)
- Requirements Traceability

## Görülən işlər

- Maraqlı tərəflərin ehtiyaclarının təhlil edilməsi
- Biznes və istifadəçi tələblərinin müəyyənləşdirilməsi
- Functional və Non-Functional Requirements hazırlanması
- User Story və Acceptance Criteria hazırlanması
- Biznes proseslərinin BPMN 2.0 ilə modelləşdirilməsi
- Use Case və ERD modellərinin hazırlanması
- Tələblər arasında əlaqələrin Requirements Traceability vasitəsilə izlənməsi
- Mövcud problemlərin təhlili və alternativ həllərin müəyyənləşdirilməsi
